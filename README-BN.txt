Amjad Creates Studio — Android project

এই প্রজেক্টে ৪টি পেজে মোট ২০০টি ভিডিও প্যাকেজ আছে। প্রতিটি ভিডিওতে বাংলা শিরোনাম, আলাদা প্রম্পট, ৪টি হ্যাশট্যাগ এবং আলাদা কপি বাটন আছে। প্রতিটি প্রম্পটে আবু বক্কর, হাবিবা, ইউসুফ ও বুশরা চারজনের উপস্থিতি ও চরিত্রের ধারাবাহিকতার নির্দেশনা দেওয়া আছে।

APK বানানোর সহজ উপায়:
1. ZIP Extract করুন।
2. GitHub-এ নতুন repository খুলে সব ফাইল upload করুন।
3. Actions ট্যাবে Build Amjad Creates Studio APK workflow চালান।
4. সফল হলে Artifacts থেকে Amjad-Creates-Studio-APK ডাউনলোড করুন।
5. APK ইনস্টল করুন।

দ্রষ্টব্য: এই ZIP হলো Android source project; APK এখানে compile করা হয়নি। Google Flow-তে একই চরিত্রের reference image বারবার ব্যবহার করলে মুখের ধারাবাহিকতা ভালো থাকে, কিন্তু AI-generated ভিডিও শতভাগ ভুলমুক্ত হবে এমন নিশ্চয়তা নেই।
